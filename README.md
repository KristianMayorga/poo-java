# POO en Java

Colección de programas en Java que ponen en práctica los fundamentos de la **Programación Orientada a Objetos**: clases, estructuras de control, condicionales y algoritmos básicos.

## Contenido

- `Programa1/` — Estructura básica en Java
- `Programa2/` — Par o impar
- `programa3/` — Circunferencia (cálculo de área/perímetro)
- `Programa4/` — Ejercicio final del curso

## Tecnologías

- Java
